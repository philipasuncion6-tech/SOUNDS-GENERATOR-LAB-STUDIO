# SOUNDS GENERATOR LAB STUDIO

A local-first browser music studio for voice capture, voice-sample analysis, songwriting, instrumental sketches and animated lyric-video experiments.

## Studio workflow

**VOICE SAMPLE → VOICE PROFILE → SONG BLUEPRINT → EDITABLE LYRICS → INSTRUMENTAL WAV → ANIMATED LYRIC VIDEO (WEBM)**

## Current features

- Microphone recording with explicit voice-use consent and local playback.
- Browser-side signal level and lightweight pitch estimates from the captured sample.
- Song blueprint controls for English, Filipino and Taglish lyrics.
- Mood presets: hopeful, romantic, heartbreak, inspirational, celebration and peaceful.
- Full, short and verse/chorus song structures.
- Style selection and adjustable target BPM for the synthesized instrumental.
- Editable lyrics, plain-text lyric export and JSON project export.
- Original browser-synthesized instrumental preview and WAV download.
- Animated lyric video export as WebM with the generated backing audio, where MediaRecorder and canvas capture are supported.
- Responsive mobile-first interface.

## Important limitations

This is a local browser studio, not a hosted AI music service. Lyrics are assembled from editable templates; they are not generated by a cloud AI model. The instrumental is an original synthesized demo arrangement, not a professional multitrack recording. Voice Profile estimates signal level and pitch from a sample; it does not identify a speaker or establish a complete vocal range. No AI singing or voice cloning is included.

Video export currently targets **WebM** because MP4 recording support varies across browsers and devices. Keep the browser tab open while rendering. Longer recordings and older phones may run out of memory.

Microphone recordings and project exports are handled in the browser. Downloaded project JSON contains the project text and settings, not the recorded voice sample.

## Browser notes

Use a current browser over HTTPS and grant microphone permission. Web Audio, MediaRecorder, canvas capture and file downloads must be supported for their respective features. If a device cannot render WebM, use a supported desktop browser.
